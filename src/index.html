APPLICATION

Settings

Notifications

Use the Windows installer and launch Orbit Desktop from its Start menu shortcut. The installer registers the app identity used for desktop alerts.

Enable Notifications and Orbit Desktop banners in Windows Settings. Turn off Do Not Disturb (or Focus assist on Windows 10) while testing. An in-app alert also appears at the bottom right. Activity records notification requests and errors; a request does not confirm that Windows displayed a banner.

Integration status

Best Buy US, Amazon US, Target, Walmart US: demo tasks and account assignments only. Demo tasks remain simulated. Target Live separately supports a user-signed-in browser, page observations, and a manual checkout review; automatic purchases are not implemented.

Tasks are stored locally under the app's user data folder. Active demos pause on exit. Account and proxy credentials are stored locally with Windows credential protection. Cards and retailer sessions are not stored. Credentials cannot be moved to another Windows user or computer.

Live monitoring and checkout require a separate retailer integration. This app is independent of StellarAIO, ValorAIO, and Target.
